<h1 align="center">Yoru</h1>

Desktop-клиент для [Mihomo](https://github.com/MetaCubeX/mihomo): серверы, подписки, выбор маршрута для каждого приложения или домена, DNS и диагностика. Интерфейс на русском, тёмная и светлая темы, собственная рамка окна.

## Возможности

- Импорт ссылок серверов, подписок со списком ссылок (в том числе Base64) и Mihomo YAML.
- VLESS/Reality, VMess, Trojan, Shadowsocks, Hysteria/Hysteria2, TUIC, WireGuard и другие форматы, поддержанные импортёром и ядром. Дополнительные поля YAML сохраняются при импорте.
- Ручной выбор сервера, резерв по приоритету, минимальная задержка и балансировка. Настраиваемые URL, интервал и тайм-аут проверки.
- Правила для доменов, IP, имён и путей процессов. Выбор запущенного процесса; создание правила из активного соединения.
- Наборы маршрутизации, разделение DNS, Fake-IP и исключения TUN. По умолчанию остальной трафик идёт напрямую (`MATCH,DIRECT`).
- TUN, системный прокси, трей, автозапуск и автоподключение.
- Активные соединения, трафик, логи с фильтрами, копированием, ZIP-экспортом и ротацией.
- Ядро включается в сборку для целевой ОС и архитектуры. Обновление ядра доступно в приложении.

## Сборка

Нужны Go 1.25+, Node.js с npm и [Wails v3](https://v3.wails.io/) (`v3.0.0-beta.8`). Windows использует WebView2, macOS требует Xcode Command Line Tools; Linux требует зависимости Wails/GTK/WebKit для своего дистрибутива.

```sh
git clone git@github.com:d0kur0/Yoru.git
cd Yoru
go install github.com/wailsapp/wails/v3/cmd/wails3@v3.0.0-beta.8
wails3 build
```

Перед компиляцией `cmd/bundle-core` скачивает и проверяет Mihomo для целевой платформы. Сборка требует доступа к GitHub; готовое приложение использует встроенное ядро. Параметры `GOOS` и `ARCH` выбирают целевую платформу; одна обычная сборка содержит одно ядро.

Windows: `bin/Yoru.exe`. На macOS `wails3 package` создаёт пакет приложения. Linux-сборка предусмотрена, но работа desktop-интеграций на Linux пока не проверена.

```sh
# Запускать из корня репозитория после установки frontend-зависимостей.
npm --prefix frontend install
npm --prefix frontend run build
go test ./...
go vet ./...
node --test frontend/*.test.mjs frontend/src/reference/*.test.mjs
```

На Windows PowerShell можно передать найденные тесты через `Get-ChildItem frontend,frontend/src/reference -Filter *.test.mjs | ForEach-Object FullName`.

## Данные и совместимость

Для совместимости с ранними сборками каталог данных сохранён:

- Windows: `%APPDATA%/MihomoDesktop`.
- macOS: `~/Library/Application Support/MihomoDesktop`.
- Linux: каталог `MihomoDesktop` внутри `os.UserConfigDir()`.

`config.json` содержит настройки, подписки и ключи серверов. `runtime/config.yaml` содержит конфигурацию ядра. Логи ограничены размером, количеством файлов и сроком хранения. Настройки темы ранних сборок остаются в каталоге `Tiho`. Старые форматы резервных копий поддерживаются.

Экспорт настроек содержит секреты. Не публикуйте его, ссылки подписок или рабочий YAML в issues.

## Состояние проекта

Проект активно разрабатывается. Основная проверяемая платформа — Windows. macOS/Linux требуют отдельных проверок упаковки, разрешений и сетевых интеграций.

TUN требует соответствующих прав ОС. Настройка корпоративного VPN зависит от его маршрутов и DNS; готовый пример не гарантирует совместимость с конкретной сетью. Изменения параметров подключения применяются после перезапуска ядра.

## Исходники

- `internal/core` — конфигурация, YAML, импорт, ядро, сеть и логи.
- `frontend/src/reference` — активный интерфейс.
- `main.go`, `vpn*.go`, `tray.go` — Wails API и desktop-интеграция.
- `assets` — иконка приложения и варианты для трея.
- [Настройка DNS](docs/DNS.md).

Mihomo запускается отдельным процессом. Его лицензия GPL-3.0 и ссылка на исходники указаны в `internal/bundled/payload`; лицензии сторонних UI-ресурсов находятся в `third-party`.
