# Yoru на macOS

Перетащите Yoru из DMG в Applications и запускайте из Applications или Launchpad от своего пользователя. Доступны отдельные сборки для Apple Silicon и Intel. Текущие сборки подписаны ad-hoc, без notarization Apple; проверка доверия к приложению и запрос прав для TUN являются отдельными шагами.

## Права для TUN

При подключении с включённым TUN Yoru через AppleScript открывает системный диалог пароля администратора. Разрешение запускает отдельный служебный процесс без окна, который управляет Mihomo с правами root. GUI, `config.json` и пользовательские настройки остаются под вашим пользователем.

Служебный процесс работает только в текущей сессии. Постоянный daemon, правило `sudoers` и `setuid` не устанавливаются. При новом подключении TUN пароль может понадобиться снова, включая автоподключение после запуска приложения. При отмене диалога подключение не выполняется.

Для запуска с правами root допускается только встроенное ядро или ядро из официального релиза Mihomo на GitHub, соответствующее выбранной версии и проверенное по контрольной сумме. Произвольный исполняемый файл не получает эти права. Ядро работает в отдельном закрытом временном каталоге. При отключении или потере связи с GUI, в том числе после аварийного завершения окна, служебный процесс останавливает ядро.

TUN автоматически выбирает свободный интерфейс `utunN`. Если DNS Cisco указан как `192.0.2.53#utun5`, суффикс относится только к маршруту DNS. Он не закрепляет интерфейс Yoru за `utun5`. Для Cisco используйте его фактический интерфейс, который может измениться после переподключения; подробнее в [инструкции DNS](DNS.md#cisco-secure-client--anyconnect).

## Если раньше запускали весь Yoru через sudo

Такой запуск мог оставить файлы владельца root в пользовательском каталоге настроек. Сначала отключитесь и полностью завершите прежний экземпляр Yoru, затем в Terminal своего обычного пользователя выполните:

```sh
sudo chown -R "$(id -un):$(id -gn)" "$HOME/Library/Application Support/Yoru"
```

Команда возвращает владение только каталогом настроек Yoru. После этого запустите приложение из Launchpad. Запускать весь GUI через `sudo` больше не требуется.

## Проверка на реальном Mac

Первая живая проверка этого способа запуска на Mac ещё не выполнена. Сборка и автоматические тесты не подтверждают работу системного диалога, TUN и DNS на устройстве.

Для проверки запустите приложение из Launchpad, подключитесь с TUN, подтвердите диалог и проверьте внешний HTTPS и DNS. Отключитесь и убедитесь, что ядро остановилось; повторите подключение и проверьте отмену запроса пароля. Отдельно проверьте завершение ядра после аварийного закрытия GUI и сохранение настроек после обычного перезапуска. При использовании Cisco проверьте корпоративные DNS и HTTPS при одновременно активных VPN.
