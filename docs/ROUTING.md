# Порядок маршрутизации

В разделе **Правила** обычные правила и наборы находятся в одном списке. В режиме **По правилам** Mihomo проверяет его сверху вниз до первого совпадения. Стрелки перемещают строку относительно любых соседей, независимо от типа. Последняя строка **Остальной трафик** определяет маршрут, если ни одно условие не подошло.

Например, чтобы браузер использовал VPN, а сайт открывался напрямую, поставьте правило домена `company.example → Напрямую` выше правила приложения `chrome.exe → Через VPN`. Если домен входит в набор, поднимите этот набор выше правила приложения. При обратном порядке первым совпадёт правило браузера.

Набор объединяет несколько условий с одним маршрутом и занимает одну позицию в очереди. Его условия проверяются подряд на этой позиции: домены, части доменов, приложения, затем IP-подсети. Выключенный набор остаётся на месте, но не участвует в обработке. Новые правила и наборы добавляются в конец очереди перед **Остальным трафиком**; после добавления их можно поднять.

Изменения порядка применяются при сохранении к новым соединениям работающего ядра. Открытые соединения сохраняют прежний маршрут. Если ядро остановлено, сохранённая очередь используется при следующем подключении. В глобальном и прямом режимах очередь не определяет маршрут.

## DNS и обход TUN

DNS набора и исключение его доменов из Fake-IP действуют отдельно от очереди маршрутизации. Их назначение сохраняется при перемещении набора.

**Обход TUN** исключает IP-подсети и адреса DNS набора из виртуального адаптера. Эти адреса идут по маршрутам ОС и не попадают в очередь Mihomo. Положение строки не отменяет такое исключение. Изменение параметров адаптера применяется после перезапуска ядра; приложение показывает ожидающее изменение.

## Существующие настройки и импорт

При первом открытии старой конфигурации сохраняется её прежний порядок: сначала наборы, затем обычные правила. Обновление само не меняет направление трафика. После этого обе сущности можно перемещать между собой.

Полная резервная копия настроек сохраняет общий порядок. Импорт наборов добавляет новые наборы в конец очереди и не переставляет существующие строки. Экспорт набора переносит его условия и параметры, а место в очереди задаётся на принимающем устройстве.

В конфигурации общий порядок хранится в `routeOrder` как ссылки `{kind: "rule" | "set", id}`. Массивы `rules` и `sets` сохраняют содержимое сущностей. Отсутствующие в очереди записи добавляются в конец, устаревшие и повторные ссылки удаляются при нормализации. Старые версии Yoru не поддерживают этот порядок.
