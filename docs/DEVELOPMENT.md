# Разработка Yoru

Нужны Go 1.25+, Node.js 24.10+ с npm и Wails `v3.0.0-beta.8`. На Windows приложение использует WebView2; для установщика нужен NSIS в `PATH`. На macOS установите Xcode Command Line Tools.

```sh
go install github.com/wailsapp/wails/v3/cmd/wails3@v3.0.0-beta.8
npm ci
npm --prefix frontend ci
npm --prefix frontend run build
npm test
go test ./...
go vet ./...
wails3 build
```

`npm test` запускает все frontend-тесты и проверки метаданных релиза. Go-тесты покрывают конфигурацию, импорт, генерацию YAML, изменения работающего ядра, замеры и backend-контракты. Тесты не подтверждают работу TUN, системных разрешений и внешних VPN на реальной машине.

`wails3 build` создаёт `bin/Yoru.exe` на Windows или `bin/Yoru` на macOS. `wails3 package` собирает NSIS-установщик на Windows или `bin/Yoru.app` на macOS. Упаковка DMG в CI выполняется через `hdiutil`.

Перед компиляцией `cmd/bundle-core` получает Mihomo с официального GitHub и сохраняет ядро для целевой ОС/архитектуры. Сборке нужен интернет; готовое приложение извлекает встроенное ядро. Одна обычная сборка содержит одно ядро, поэтому Intel и Apple Silicon выпускаются отдельно.

## Карта исходников

| Каталог | Назначение |
| --- | --- |
| `internal/core` | Конфигурация, маршруты, DNS, импорт, управление ядром, замеры и журналы |
| `frontend/src/reference` | Активный интерфейс приложения |
| `main.go`, `vpn*.go`, `tray.go` | Wails API и desktop-интеграция |
| `build` | Метаданные, платформенные задачи и установщики |
| `scripts`, `.github/workflows` | Проверки версий и автоматические релизы |

## Безопасные скриншоты

```sh
npm --prefix frontend run dev -- --host 127.0.0.1
```

Откройте `/demo.html` по адресу, который напечатает Vite. Этот вход использует настоящий интерфейс и вымышленные данные из `frontend/src/demo.mjs`: домены `.example`, демонстрационные серверы и счётчики. Нативный backend не подключается, пользовательские настройки не читаются, изменения не сохраняются. Файл не включён в production entrypoint Vite.

Штатное окно приложения — 1160 × 760; минимальное — 800 × 640. Снимки README находятся в `docs/screenshots`. Перед заменой проверьте, что в кадре нет личных подписок, адресов, ключей и рабочих доменов. Скриншоты демонстрируют интерфейс, а не результаты сетевых измерений.

## Версии

Не редактируйте версии вручную перед коммитом. [semantic-release](RELEASING.md) обновляет UI, native metadata, установщики и CHANGELOG после успешных сборок. Для обычных изменений используйте Conventional Commits.
