# Работа через AI Root

Поддерживаемая карточка и фактическая спека: `docs/projects/yoru.md` в AI Root. Исходники и эта кодовая документация принадлежат своей репе; общие правила, навыки и память хранятся в AI Root.

После клонирования AI Root выполни из его корня:

```powershell
python scripts/project.py prepare yoru
```

Команда получает код в ignored `repos/yoru`, создаёт ignored `.ai-root.local.json`, обновляет общую память и готовит настроенные инструменты кода. Открой выведенный путь отдельным workspace в DeepSeek Harness и создай новый чат. Зависимости продукта устанавливаются отдельно по README. Старые локальные env, аккаунты и профили не копируются.

`.ai-root.local.example.json` является переносимым шаблоном. Фактический binding содержит машинный путь и не коммитится. При самостоятельном clone вне managed `repos/` создай локальную привязку по шаблону, а LSP зарегистрируй отдельно по `docs/code-tools.md` AI Root. Codex/Claude/Cursor читают `AGENTS.md` через свои указатели; клиенту вне Harness потребуется отдельно подключить HTTP MCP по документации AI Root. Сам Markdown не устанавливает MCP в другой клиент.

Не запускай TUN, Mihomo, VPN-подключение или изменение системной маршрутизации ради анализа. macOS/TUN проверяется отдельно на целевой машине.
