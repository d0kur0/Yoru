# Yoru

## Общая среда AI Root

Прочитай локальный `.ai-root.local.json`, затем по его `root` открой:

1. `config/agents/CLI_TOOLS.md` с правилами общения, Windows и CLI.
2. `docs/projects/yoru.md` с картой проекта и предметными инструкциями.
3. `.agents/skills/ai-root-memory/SKILL.md` с порядком поиска и сохранения знаний.

Общий Basic Memory: `http://127.0.0.1:3085/mcp`, текущий проект `yoru`, общие знания `ai-root`. Канон новой памяти: `<root>/.memory/projects/yoru/`. Документация рядом с кодом остаётся в этой репе; `_sources` является копией только для чтения. Общие скиллы находятся в `<root>/.agents/skills/`, предметные навыки читай по карте проекта. Если binding отсутствует, следуй `docs/AI-WORKSPACE.md`, не угадывай машинный путь.

Не запускай TUN, Mihomo, VPN-подключение или изменение системной маршрутизации ради анализа. macOS/TUN проверяется отдельно на целевой машине.
